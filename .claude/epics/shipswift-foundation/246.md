# Task: 守卫扩展与新建（含条件差集守卫）

## Description

把本仓既有的质量守卫扩展到新 target，并新建两条（可能三条）守卫。
**这是"新 target 不会变成垃圾抽屉"的唯一机器保障。**

## Acceptance Criteria

### 扩展既有守卫
- [ ] `BoolExemptionGuard` / `BoolParameterScanner`：扫描根 `BoolExemptionGuard.swift:43`
      单根 → **多根列表**；台账键加 target 前缀
- [ ] `AccessibilityStringLiteralGuard`：`:189` 同上；**按 target 分辨各自的 `.module`**

### 新建守卫
- [ ] `EffectsColorLiteralGuard`——禁色相字面量（`.cyan` / `Color(red:green:blue:)` /
      `.white.opacity(…)`）；射程仅新 target
- [ ] `ChromeTextLiteralGuard`——扫 `Text("…")` / `Label("…"` 裸字面量（公约 **A 类**）；
      射程仅新 target，**不回溯改造 CoreDesign 现状**
- [ ] **条件项：差集守卫**——⚠️ **若 task 001 的 AD-4 对 Effects / Shaders 选 a（推荐走向），
      本 task 必须交付它**。形态按 AD-4 所选（独立 `docs/effects-registry.json` 双向差集
      **或** 锚 `docs/components/<slug>.md`）；射程 = public `View` / `ViewModifier`；
      `transition` / `modifier` 手工维护并在盲区台账留痕

### 防假绿（关键）
- [ ] **根列表只含当下已存在的 target**（Effects / Charts），**每个根断言目录存在**
      ——fail-closed
- [ ] **每条新守卫附带一个会触发红的 fixture**，或临时植入违规文件实跑一次并留证
      ⚠️ **仅断言"目录存在"挡不住假绿**：本 task 落地时两个新根是**空目录**（组件在
      Epic A 才来），新守卫在 0 个文件上必绿
- [ ] **NFR-4 grep 断言**：零 `@unchecked Sendable`。⚠️ **根列表与上面四条守卫同源，
      只含已存在的 target**——对不存在的 `Sources/CoreDesignShaders/` 做 grep 无命中即绿，
      正是本 task 要防的 fail-open。Shaders 根由 `shipswift-shaders` 的 B-1 加入

### 不放松既有断言
- [ ] **既有 CoreDesign 判据字面不变**（FR-10）：
      `docs/bool-exemptions-baseline.json` 的 `maxEntries` **32** / `sourceSites` **35**、
      `ComponentTextParamGuard` 的 `== 31`、`ComponentRegistryGuard` 的 **47** / **25**
      逐字不变，重构未放松任何现有断言

## Technical Details

### ⚠️ `ComponentTextParamGuard` 不在本 task 处理

它**只能守 B 类**（public init 的裸文本参数），且定义域是**登记表条目**
（`ComponentTextParamGuard.swift:228-242` 按 `repo == "coredesign"` 取 `textParams`
并硬断言 `== 31`）。公约 **G-8** 逐字「FR-4 判据以**登记表条目**为定义域」。

它**守不到** FR-7 要求的 **A 类** chrome 文案——公约 **G-4**（`component-contract.md:1017`）
明载「A 类文案不经任何一路进入 FR-4 的机器视野……评审（无机器判据）」，
**连 CoreDesign 自己都没守住 A 类**。`ChromeTextLiteralGuard` 就是为此新建的。

⇒ `ComponentTextParamGuard` 的**扩展与 FR-7 边界编码归 `shipswift-effects` 的 A-6`**
（与 `47→51` 同一处），不在本 task。

### ⚠️ `TouchTargetTests` 结构上不适用

`TouchTargetTests.swift:3` 是 `@testable import CoreDesign`、`:57` 整 suite `#if os(iOS)`。
往里加 `BeforeAfterSlider` 会让 `CoreDesignTests` 依赖图含新 target ⇒ **违反 NFR-5②**，
把 task 002 立的那条 `jq` 判据判红。
⇒ 本 task 不动它；两个真交互件（`BeforeAfterSlider` / `GlassOrb`）的触控目标测试
由 Epic A / B 在**各自的独立测试 target** 里同形态实现。
