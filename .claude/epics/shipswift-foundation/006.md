# Task: 【闸②】C-6 逐 shader 许可裁定表

## Description

逐个核验 28 个 Metal shader 的**许可来源**，产出 `docs/shader-provenance.md` 裁定表。
本 task 是 `shipswift-shaders` 的**启动闸②**。

⚠️ **这是一个真实的法律风险，不是形式流程**：上游 ShipSwift 的
`ACKNOWLEDGEMENTS.md` **只标注了 7/28 个 shader 的来源**（ShaderKit 5 个 + Star Nest +
Warping Loupe/GlassOrb，均 MIT）。**其余 21 个零来源标注**，而 Plasma / Voronoi /
SimplexNoise / Metaballs / Water / FractalClouds / Swirl / InkSmoke / SmokeRing /
Starfield / NeuroNoise 这类经典 shader 的常见出处 **Shadertoy 默认许可是 CC BY-NC-SA**
（非商用 + 传染性 share-alike），与 MIT 分发的设计系统**不兼容**。

## Acceptance Criteria

- [ ] `docs/shader-provenance.md` **覆盖全部 28 个 shader，无空裁定**
- [ ] 表结构固定为 **`shader | 原始出处 | 许可 | 证据链接 | 裁定`**
- [ ] **裁定取值仅三种**：
      - `已追到兼容许可`——MIT / BSD / PD / CC0 的原始实现 ⇒ 可移植，须转载原始许可
      - `clean-room 重写`——教科书算法（Simplex noise 有 Ashima/Gustavson 的 MIT/PD
        参考实现；Voronoi / Plasma / Metaballs 同属公开算法）
      - `不落地`——追不到兼容许可、也不属可 clean-room 的公开算法
- [ ] **那 7 个已知 MIT 件的传递来源已核**（ShaderKit 自身的 shader 是否又移植自
      Shadertoy，上游没说）——**不得当作预先通过**
- [ ] `N_B` 已按经济性方法反推出**具体数字**：**B 固定成本（task 005 交付 A）÷
      每 shader 边际成本（task 005 交付 B）**。⚠️ **不取 7**——7 恰好等于已知 MIT 来源数，
      取它等于"表填满即通过"，是同义反复
- [ ] **闸②的通过判定**：可落地数 **≥ `N_B`** ⇒ 闸过，`shipswift-shaders` 可启动；
      **< `N_B`** ⇒ 闸不过，该 epic 整体不启动
- [ ] **`ACKNOWLEDGEMENTS.md` 的骨架由本 task 建**（本仓此前无此文件）。
      ⚠️ **骨架 = 表头 + 说明 + 上游许可全文转载**；**逐 shader / 逐组件的条目由各自
      落地的 task 追加**——闸②若不过，ACK 不得署名仓内并不存在的 shader
- [ ] **go/no-go 结论有 GitHub 侧落点**：在本 issue 的关闭评论里固定记录
      **"B 启动 / 不启动 + `N_B` 值 + 可落地 shader 名单"**

## Technical Details

### ⚠️ 用正向裁定，不用"证明来源不明"

"来源不明"是要证一个否定，做不到。可操作的是**正向裁定**：每个 shader 一行，
只有裁定为前两类的才落地。

### ⚠️ clean-room 条款必须写成可核的产物条款

**不要**写成"不看 ShipSwift 的 `.metal`"——那既不可执行（本 PRD 的调研本身已 grep 过
全部 34 个 `.metal`），法律风险也不在读 ShipSwift（它是 MIT），
**而在于 ShipSwift 的文件本身若是 CC BY-NC-SA 衍生**。

可核的三条：
1. provenance 表的 `证据链接` **必须指向参考实现**，不得指向 ShipSwift；
2. 新 `.metal` 文件头注明参考实现 URL + 其许可；
3. 评审**对照参考实现**核，不对照 ShipSwift。
