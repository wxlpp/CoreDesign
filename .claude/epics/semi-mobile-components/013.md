# Task: Phase 3 — 收尾串行(注册/索引/断言汇入/发版)

## Description

`semi-mobile-components` epic 的收尾任务，在 Phase 1 全部 10 个组件 + 1 个增强包（Issue 002–012）合入 `epic/semi-mobile-components` 后串行执行，统一处理并行阶段刻意搁置的共享文件改动与整体验证/发版。本任务不可并入 001——001 是 Phase 1 的阻塞前置，同一任务不能既解锁 Phase 1 又在 Phase 1 全部完成后收尾，会构成依赖环。

涵盖工作（对应 epic Implementation Strategy Phase 3）：

- **宿主画廊注册**：编辑既有已提交文件 `App/Sources/Previews.swift` 与 `App/Sources/ComponentData.swift`（`ComponentMeta.all` + `ComponentCategory` 归类，驱动宿主画廊/detail 导航）——两者均为编辑而非新增 App 源文件，不触发 CLAUDE.md 记录的 worktree + xcodegen 盲区。
- **共享断言汇入**：把各新交互组件（Rating / Radio / PinCode / FloatButton / TagInput 等约 5–7 个）的 touch-target（≥44pt）断言汇入共享 suite `Tests/CoreDesignTests/TouchTargetTests.swift`（Issue #123 建立的基础），dynamic-type / 塌列断言汇入 `DynamicTypeLayoutTests.swift`；两个 suite 均为 `#if os(iOS)`，在 macOS 上是空 suite（假绿），必须跑 CI 的 xcodebuild iOS Simulator 腿（或本地 `xcodebuild test -scheme CoreDesign -destination 'platform=iOS Simulator,...'`）才作数。
- **文档索引更新**：更新 `docs/README.md` 组件索引，新增本 epic 交付物各分类条目（组件数 24 → 34）。
- **宿主视觉复查**：用 `scripts/run-preview.sh` 跑起预览宿主做批量视觉复查，交 ios-visual-reviewer 做整体判定（epic Success Criteria SC-6，无 BLOCK）。
- **Typography 墓碑文档**：新增 `docs/components/typography.md`，给出迁移指引（改用 `.coreFont` + 原生 `Text` modifier）。
- **字符串补登**：并行期各 Issue 记录下来的漏登记 `Localizable.strings`（+`.stringsdict`）键，在本任务统一补登（Phase 1 期间这两个文件禁止改动，缺口延后到此处收口）。
- **版本 / BREAKING-CHANGES 收尾**：本 epic 全部交付物为纯新增、无破坏性变更（NFR-6），按仓库既有发版流程收尾版本号与 `BREAKING-CHANGES` 记录（预期为非破坏性收尾条目）。
