# Task: FloatButton 悬浮按钮

## Description

新增 FloatButton 能力——**净新增仅 extended 形态（图标+文字的胶囊玻璃按钮）+ 定位使用文档**。icon-only FAB 情形**不重造**，直接封装/引导调用方使用既有 `Components/Button/styles/CircularGlassButtonStyle.swift`（其 doc-comment 已声明服务"任何漂浮于内容之上的圆形 icon 按钮"）。本任务的核心交付是一个新的 `ButtonStyle`（胶囊形，含 icon+文字）与一份说明 FAB 定位取舍（何时用 overlay FAB、何时用 `.safeAreaBar`/`BottomInputBar`）的文档。

## Acceptance Criteria

### API 形态
- [ ] 新建 `Sources/CoreDesign/Components/Button/styles/ExtendedFloatButtonStyle.swift`
- [ ] `public struct ExtendedFloatButtonStyle: ButtonStyle`，形态对齐仓库既有按钮样式模式（`*ButtonStyle: ButtonStyle`）——**不**引入 `ButtonRoleStyleRole` 参数化（本样式是玻璃浮层视觉，非角色配色，与 `CircularGlassButtonStyle` 同类，不与 `LightButtonStyle` 等角色按钮混同）
- [ ] `public init(size: ControlSize = .large)`（尺寸档位来源与 `CircularGlassButtonStyle` 一致，走 `CoreControlMetrics.height(for:)`）
- [ ] `public extension ButtonStyle where Self == ExtendedFloatButtonStyle { static var extendedFloat: ExtendedFloatButtonStyle; static func extendedFloat(size: ControlSize) -> ExtendedFloatButtonStyle }`
- [ ] 调用方用法：`Button { } label: { Label("New", systemImage: "plus") }.buttonStyle(.extendedFloat)`——`configuration.label` 直接承载调用方的 icon+文字组合，样式本身只负责胶囊玻璃背景与内边距，不重新拼装 icon/文字排布

### 视觉
- [ ] 形状：`Capsule(style: .continuous)`
- [ ] 背景：复用 `FloatingGlassModifier`（`.floatingGlass(in:)`）或 `TelegramGlassButtonModifier`——**不新写**玻璃背景绘制逻辑，与 `CircularGlassButtonStyle`/`BottomInputBar` 保持同一套玻璃语汇
- [ ] 高度：`CoreControlMetrics.height(for: self.size)`，横向内边距走 `CoreSpacing.md`/`lg`
- [ ] 按压态：`.opacity(configuration.isPressed ? 0.9 : 1)`，与 `CircularGlassButtonStyle` 一致
- [ ] icon 强调色：若样式内对 label 做额外着色，须经 `.tint`（`ShapeStyle.tint`），不得写死 `Color.accent`（FR-3）——**推荐**不额外着色，交给调用方 `Label` 自身的 `.foregroundStyle`/`.tint`

### Icon-only 引导
- [ ] doc-comment 显式声明："icon-only 悬浮按钮请使用 `CircularGlassButtonStyle`（`.circularGlass`），本样式只服务图标+文字的 extended 形态"
- [ ] 不新建任何 icon-only FAB 类型/静态成员

## Technical Details

`ExtendedFloatButtonStyle.makeBody(configuration:)` 结构参考 `CircularGlassButtonStyle.makeBody(configuration:)`：

```swift
configuration.label
    .frame(minHeight: diameter)
    .padding(.horizontal, CoreSpacing.lg)
    .contentShape(Capsule())
    .floatingGlass(in: Capsule(style: .continuous), isInteractive: true)
    .opacity(configuration.isPressed ? 0.9 : 1)
```

（具体是否用 `FloatingGlassModifier` 还是 `TelegramGlassButtonModifier` 由实现时二选一，两者均为既有玻璃语汇，选择理由写入 doc-comment；不得重新手写 `.glassEffect` 调用。）

**测试重点**：本样式主要是视觉合成，若无可提纯的受控/格式化逻辑，`Tests/CoreDesignTests/FloatButtonTests.swift` 可退化为"样式可实例化 + 静态成员可访问"的最小编译期验证测试；不得因此跳过测试文件本身。

**不做的事**：不实现自动轮播/多按钮聚合等 Semi FAB 的扩展形态（超出 PRD FR 范围）；不碰 `Localizable.strings`（本样式无自有文案，调用方 `Label` 自带文案）、共享测试 suite、`Previews.swift`、`ComponentData.swift`。
