# Task: Rating 评分

## Description

`Binding<Double>` 驱动的星级评分组件。星数可配置、支持只读模式、支持半星（0.5 步进）。星形绘制复用现有 `Shape/StarShape.swift`，不重新实现五角星路径。强调色走 `.tint`，支持 VoiceOver adjustable（可调整 value）。

## Acceptance Criteria

- [ ] `Rating` 为 public 类型，public init，接收 `Binding<Double>` 驱动当前评分
- [ ] 星数可配置（如 `count: Int`，默认 5）
- [ ] 支持只读模式（如 `isReadOnly: Bool` 参数），只读时不响应手势
- [ ] 支持半星步进（如 `allowsHalfStar: Bool` 或 `step: Double`），开启时手势按 0.5 递增/递减
- [ ] 星形绘制复用 `Shape/StarShape.swift`（`StarShape()`），不重新实现五角星路径
- [ ] 选中星的填充色经 `.tint`（`TintShapeStyle`）取色；未选中星走 `FillColors` / `BorderColors` 中性色，不写死 `Color.accent`
- [ ] VoiceOver：`.accessibilityAdjustable()` + `accessibilityValue` 展示当前分值，支持 increment / decrement 手势按 `step` 调整评分；accessibility label 使用 Phase 0 预登记的 Localizable 键
- [ ] 同文件 `#Preview`：默认 / 只读 / 半星画廊，覆盖 Light/Dark
- [ ] `Tests/CoreDesignTests/RatingTests.swift`（Swift Testing）覆盖半星步进取整、只读模式下手势不生效、边界值（0 分 / 最大星数）等受控逻辑
- [ ] `docs/components/rating.md` 撰写完成
- [ ] 无第 1 层色相硬编码、无字面 `Color.accent`

## Technical Details

- 文件落点：`Sources/CoreDesign/Components/Rating/Rating.swift`
- 星形：基于 `StarShape()`（`.fill(...)` / `.stroke(...)`）按 `value` 与星索引计算每颗星的填充比例（整星 / 半星 / 空星三态，半星可用 `.mask` 裁切实现）
- 手势：拖拽或点按更新 `Binding<Double>`，按 `step`（0.5 或 1.0）取整后写回；`isReadOnly == true` 时移除手势 modifier
- 颜色：选中态 `.foregroundStyle(.tint)`；未选中态走 `FillColors`（如 `Color.tertiaryFill`）或 `BorderColors`
- Accessibility：`.accessibilityAdjustable()` + `accessibilityValue(Text(...))` 展示当前分值文案；increment / decrement 回调按 `step` 调整 `Binding<Double>` 的值，并 clamp 在 `0...count`
