# Task: Timeline 时间线

## Description

纵向排列的时间线组件，节点 + 连线 + 右侧内容。节点状态色直接复用 `StatusLevel`（`info/success/warning/danger`），不新增公开状态语义枚举。支持自定义节点视图与右侧任意内容。

## Acceptance Criteria

- [ ] `Timeline` 为 public 类型，public init，纵向排列节点（node）+ 连线（line）+ 右侧内容（content）
- [ ] 节点状态色直接复用 `StatusLevel`（`info/success/warning/danger`）映射到 `StatusColors`，不新增公开状态语义枚举（承接架构决定：Timeline 节点状态色复用 `StatusLevel`）
- [ ] 支持自定义节点视图（调用方可传入图标 / 头像等替代默认圆点），以及节点右侧任意内容通过 `@ViewBuilder` 传入
- [ ] 连线颜色复用 `BorderColors` / `Color.dividerDefault`
- [ ] 同文件 `#Preview`：默认圆点节点 + 自定义节点画廊，覆盖 4 种 `StatusLevel` 状态色，Light/Dark
- [ ] `Tests/CoreDesignTests/TimelineTests.swift`（Swift Testing）覆盖节点状态 → 颜色映射等受控/格式化逻辑
- [ ] accessibility：节点状态 label 使用 Phase 0 预登记的 Localizable 键；若本组件所需键未登记，本 Issue 内暂用已登记键或英文字面量 + TODO 注释标记，不修改 `Localizable.strings`，汇入留给 013
- [ ] `docs/components/timeline.md` 撰写完成
- [ ] 无第 1 层色相硬编码、无字面 `Color.accent`

## Technical Details

- 文件落点：`Sources/CoreDesign/Components/Timeline/Timeline.swift`
- 节点数据模型建议：`public struct TimelineItem { let status: StatusLevel; let node: AnyView?; let content: AnyView }` 或等价 ViewBuilder-based API（`node` 为 `nil` 时使用默认圆点），具体形态以 SwiftUI 惯例为准，保持 public 导出
- 默认节点：圆点，颜色取 `status` 对应的 `StatusColors` 前景/实色 token（如 `statusSuccessEmphasis` / `statusDangerEmphasis` / `statusAttentionEmphasis` / `statusAccentEmphasis`）
- 连线：相邻节点之间的纵向连线，使用 `Color.dividerDefault` 或 `BorderColors.borderDefault`，宽度走 hairline
- 若需要高亮"最新/当前"节点等交互态强调色，走 `.tint`，不写死 `Color.accent`
