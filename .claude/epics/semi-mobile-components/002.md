# Task: Skeleton 骨架屏

## Description

用 `.redacted(reason: .placeholder)` 作为占位基座，叠加独立的 shimmer 扫光动效 modifier，实现骨架屏加载态。line / rect / circle 三种占位形状可独立使用，也可组合拼装出真实布局的骨架；`isLoading` 参数控制占位态与真实内容之间的切换。

- [ ] 提供 `isLoading: Bool` 开关：为 `true` 时展示占位形状，为 `false` 时展示调用方通过 `@ViewBuilder` 传入的真实内容

## Technical Details

- 文件落点：`Sources/CoreDesign/Components/Skeleton/Skeleton.swift`（shimmer modifier 同目录内实现，不落共享 `Modifier/` 目录，避免与其它并行 Issue 产生共享文件冲突）
- 三种占位形状：
  - line：文本行占位，圆角矩形 + 固定高度，可指定条数模拟多行文本
  - rect：图片/卡片占位，矩形块，尺寸由调用方指定
  - circle：头像占位，圆形
  三者均可作为独立 view 使用，也可通过 `@ViewBuilder` 组合出复合骨架布局（如"头像 + 两行文本"）
- shimmer：`ViewModifier`，用 `LinearGradient` 遮罩（`.mask`）配合位移动画（`TimelineView` 或 repeating `.animation`）实现扫光效果；渐变高亮色从 `FillColors` 派生，不新建 colorset
- `isLoading` 为 `true` 时渲染占位形状树；为 `false` 时渲染调用方通过 `@ViewBuilder content` 传入的真实内容，两者需平滑过渡（可选 `.transition`）
- 遵循仓库 Modifier 约定：shimmer 以 `View` 扩展形式暴露（如 `.skeletonShimmer()`），不要求调用方写 `.modifier(ShimmerModifier())`
- Skeleton 本身无强调色语义；若加入可交互占位态（一般不需要），仍需走 `.tint`，不写死 `Color.accent`
