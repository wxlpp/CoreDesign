# Task: Steps 步骤条

## Description

横向 / 纵向排列的步骤条组件，支持点状（dot）与数字（numbered）两种指示器样式。进行态（未完成 / 当前 / 完成）由 `currentIndex` 在组件内部 private 派生，不新增公开的进行态枚举；完成态与当前态的强调色经 `.tint` 取色，错误态取 `StatusLevel.danger` 对应的 `StatusColors` 映射。每一步可选标题 + 描述文案。

## Acceptance Criteria

- [ ] `Steps` 为 public 类型，public init，支持横向（`.horizontal`）/ 纵向（`.vertical`）布局，与点状（dot）/ 数字（numbered）两种指示器样式
- [ ] 进行态（未完成 pending / 当前 current / 完成 done）由 `currentIndex: Int` 在内部 `private` 计算派生，不新增公开的进行态语义枚举（承接架构决定：Steps/Timeline 不得各自新增公开状态语义枚举）
- [ ] 完成态、当前态节点的强调色经 `.tint`（`TintShapeStyle`）取色，不写死 `Color.accent`
- [ ] 每一步可标记为错误态：错误态颜色取 `StatusLevel.danger` 对应的 `StatusColors`（如 `statusDangerForeground` / `statusDangerEmphasis`），不新建公开状态枚举
- [ ] 每步支持可选标题（title）与描述（description）文案
- [ ] 同文件 `#Preview`：横 / 纵 × 点状 / 数字组合，含错误态展示，覆盖 Light/Dark 或状态画廊
- [ ] `Tests/CoreDesignTests/StepsTests.swift`（Swift Testing）覆盖 `currentIndex` → 进行态派生的受控逻辑（未完成/当前/完成边界值，含首尾索引）
- [ ] accessibility：当前步骤 label 使用 Phase 0 预登记的 Localizable 键；若本组件所需键未登记，本 Issue 内暂用已登记键或英文字面量 + TODO 注释标记，不修改 `Localizable.strings`，汇入留给 013
- [ ] `docs/components/steps.md` 撰写完成

## Technical Details

- 文件落点：`Sources/CoreDesign/Components/Steps/Steps.swift`
- 布局参数：横 / 纵向轴（可用 `Axis` 或自定义 `enum StepsAxis { case horizontal, vertical }`）；指示器样式 `enum StepsIndicatorStyle { case dot, numbered }`（此枚举属纯展示配置，非"状态语义"枚举，可公开）
- 进行态派生（private，不导出）：
  ```swift
  private enum StepsProgress { case pending, current, done }
  private func progress(for index: Int) -> StepsProgress {
      index < currentIndex ? .done : (index == currentIndex ? .current : .pending)
  }
  ```
- 颜色：完成 / 当前节点的圆点或数字底色走 `.tint`；错误态节点忽略 `progress(for:)` 结果，直接使用 `StatusLevel.danger` 映射到 `StatusColors.statusDangerForeground` / `statusDangerEmphasis`
- 纵向连线使用 `Color.dividerDefault`（`BorderColors`）
- 每步数据模型建议 `public struct StepItem { let title: String; let description: String?; let isError: Bool }` 或等价 ViewBuilder-based API，保持 public 导出
