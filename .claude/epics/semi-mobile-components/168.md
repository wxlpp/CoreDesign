# Task: TagInput 标签输入

## Description

新增 `TagInput` 组件——`Binding<[String]>` 驱动的标签输入框：已有标签以 chip 形式展示，末尾内联一个文本输入框，回车/逗号提交新增标签、点击 chip 上的删除按钮移除标签。折行**复用 `Layout/FlowLayout.swift`**（已支持任意子视图自动换行，Tag 场景是其设计初衷）；chip 单元**复用 `Tag(removable: true, onRemove:)`**——现成的 44pt 命中区删除按钮与 `"Remove tag"` 本地化键（已存在于 `Localizable.strings`，无需新登记）。除非本组件确实需要中性 token 配色（`Tag` 的配色由调用方 `Color` 参数决定，标签统一走中性色而非任意色板），才自绘 chip，并在 doc-comment 中写明理由。

## Technical Details

**折行结构**：`FlowLayout` 的 `content: () -> Content` 是 `@ViewBuilder`，可以混排任意 `View`——现有 `FlowLayout` 的 `#Preview` 已演示 `ForEach { Tag(...) }` 用法，本组件在此基础上再追加一个 `TextField` 作为末位子视图即可，无需改动 `FlowLayout.swift` 本身。

**去重判断**：`allowDuplicates == false` 时用 `tags.contains(trimmed) == false` 判断，大小写敏感（不做大小写归一化，除非 doc-comment 明确记录该取舍）。

**测试重点**（Swift Testing，覆盖受控/格式化逻辑）：
- 提交逻辑抽成可单测的纯函数，如 `static func normalizedTag(_ raw: String) -> String?`（trim + 空值判断返回 `nil`）
- 去重判断：`allowDuplicates: false` 时重复输入不追加；`true` 时允许追加
- 删除逻辑：给定标签数组与目标 index，移除后数组正确（尤其验证 `id: \.offset` 迭代在有重复值时删除的是正确的那一个，而非同名的第一个）

**不做的事**：不碰 `Localizable.strings`、共享测试 suite、`Previews.swift`、`ComponentData.swift`——留给 013。
