# Task: 庆祝与处理中动效（4 个）+ 可注入能耗 environment

## Description

落 `Confetti` / `ScanningOverlay` / `GlowSweep` / `LightSweep`，并建立 **NFR-7 的可注入
`EnvironmentValues`** —— 后者是本 epic 与 `shipswift-shaders` 之间的一条**跨 epic 契约**。

## Acceptance Criteria

### ⚠️ ~~AD-4 复判闸的触发点~~ —— **随成本模型一并撤回**（#244 第 6 轮）

AD-4 经六轮终审后收敛为「**AD-2 原样适用**」：三个 target 全走
`component-registry.json`，没有轻公约、也就没有「a vs b」这个待决问题
⇒ **复判闸失去对象，整段撤回**。

⚠️ 照录成因（本仓要求错误留痕）：该闸门在两轮里各失效一次——第 4 轮公式量纲错
（件数 − 字符数 ⇒ 阈值 −58 ⇒ 恒假）、第 5 轮三阈值并列无选择规则 ⇒ 不可判定；
且它自身的成本一进模型就把最后一格 a 也翻掉。
**一个连续两轮无法判定的闸门，本身就是结论不成立的证据。**


- [ ] 4 个 API 可用：`myView.confetti(trigger:)` / `ScanningOverlay { }` /
      `GlowSweep { }` / `LightSweep { }`
- [ ] **Confetti 粒子颜色默认取自调用方 `.tint`**，不自带彩虹色板
- [ ] **Reduce Motion**：Confetti 不播放粒子，降级为一次淡入淡出的静态庆祝层
- [ ] **burst 结束后驱动它的 `TimelineView` 停止调度或被移除**
      （⚠️ 上游用 `TimelineView(.animation)`（`SWConfetti.swift:171,435`），不是 Timer /
      DisplayLink——不要去找一个不存在的泄漏源）
- [ ] **NFR-7 后台 / 低电量行为可测**：`ProcessInfo.isLowPowerModeEnabled` 与 `scenePhase`
      在测试里不可直接切换 ⇒ 做成**可注入的 `EnvironmentValues`**（默认从系统读），
      测试注入伪值断言渲染行为。⚠️ **不接受"或文档声明"**
- [ ] **⚠️ 这两个可注入键必须 `public`**：`shipswift-shaders` 的 17 个 `colorEffect` 要
      `import CoreDesignEffects` 复用它们，而 `@Entry` 默认 internal ⇒ 不显式 `public`，
      B-2 用不了，跨 epic 契约断掉
- [ ] **可选**：若 `shipswift-shaders` 的 B-2 先于 task 007 完成，**NFR-1 性能 harness
      在本 task 落地**而非 007——避免 17 个 colorEffect 全落完才第一次跑性能闸
- [ ] 各有 `#Preview` + `docs/components/*.md`；`EffectsColorLiteralGuard` 零违规
