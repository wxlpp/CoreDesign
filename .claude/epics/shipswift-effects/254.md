# Task: 跨平台改造（4 个非纯 SwiftUI 件）

## Description

上游这 4 个件**不是纯 SwiftUI**，直接搬会破坏 CoreDesign 的 macOS 支持：

| 件 | 上游依赖 |
|---|---|
| `OrbitingLogos` | `import SpriteKit` |
| `DotSphere` | `import UIKit` |
| `CharSphere` | `import UIKit` |
| `FullScreenButton` | `navigationTransition(.zoom)`，iOS-only |

## Acceptance Criteria

- [ ] 4 件各自处理，**二选一并写明选了哪个**：
      - 重写为跨平台 SwiftUI（`DotSphere` / `CharSphere` 的 Canvas 3D 投影本身不需要 UIKit，
        大概率可重写）
      - `#if canImport(UIKit)` 隔离 + **文档标注平台限制**
- [ ] **不得降低 package 的 macOS 支持**——`Package.swift` 的 `platforms` 不变
- [ ] **AD-E 四件的平台限制已写进 `docs/components/*.md`**
      （⚠️ 此前只写在 epic 的 AD-E 里；SC 是扁平的，不写进来 decompose 会漏）
- [ ] `swift build`（macOS）绿；CI 的 iOS Simulator 腿绿
- [ ] Reduce Motion 降级路径齐备
- [ ] 各有 `#Preview` + `docs/components/*.md`

## Technical Details

`OrbitingLogos` 的 SpriteKit 依赖最重——若重写成本过高，可考虑**不落地**并在 epic 记一笔
（SC-1 允许 40 个 API 单位中 ≤3 项不可用）。
