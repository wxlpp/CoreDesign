# Task: 微交互 modifier 簇（8 个）

## Description

按 CoreDesign 公约重新实现 ShipSwift `SWChangeEffect.swift` 的 **8 个**微交互效果，
落 `CoreDesignEffects`。这是 CoreDesign 表达性视觉层最直接的缺口——`PinCode` 输错、
`Form` 校验失败、`AsyncButton` 成功，目前全部没有动效反馈可用。

⚠️ **是 8 个不是 7 个**：上游 `SWChangeEffect.swift:10-17` 逐字列了
`swShake` / `swJump` / `swSpin` / `swPing` / `swSpray` / `swRise` / `swHaptic` / `SWShine`。

## Acceptance Criteria

- [ ] 8 个 API 全部可用，命名用**裸名**（与本仓 `.surface(_:)` / `.skeletonShimmer()` 一致）：
      `.shake(trigger:)` / `.jump(trigger:)` / `.spin(trigger:)` / `.ping(trigger:)` /
      `.spray(trigger:symbol:colors:)` / `.rise(trigger:text:)` / `.haptic(_:trigger:)` /
      `Shine { }`
- [ ] 形态为 `internal struct: ViewModifier` + `public extension View`（本仓 `SurfaceModifier` 同形态）
- [ ] `import CoreDesignEffects` 后可写 `PinCode(...).shake(trigger: failedAttempts)`
- [ ] **叠加互不干扰**：同一 trigger 驱动 ≥3 个效果时行为可预期，有测试（US-1）
- [ ] **Reduce Motion 降级**：8 个中含位移/旋转/缩放的全部读
      `@Environment(\.accessibilityReduceMotion)`，开启时降级为无位移形态，测试可证
- [ ] **FR-13 分工**：装饰层 `accessibilityHidden(true)`；`.shake` 这类**承载状态语义**的
      效果，文档写明"a11y 通告由调用方提供"
- [ ] **颜色只有三个合法来源**：调用方参数 / `.tint` / CoreDesign 语义 token
      （`.spray` 的粒子色默认取 `.tint`），`EffectsColorLiteralGuard` 零违规
- [ ] **Bool 参数不照搬**：一律走 `trigger:` 值变化模式，不引入 `isActive: Bool`
- [ ] 各有 `#Preview`，进 `App/` 画廊（⚠️ `ComponentData.swift` 的写入由 task 007 串行合并）
- [ ] 各有 `docs/components/*.md`

## Technical Details

上游用 iOS 17+ 的 `KeyframeAnimator` / `PhaseAnimator` / `sensoryFeedback` / `Canvas`，
算法可借鉴；API 层与色彩层全部重写。

⚠️ **decompose 建议再拆**：8 个可按「位移类（shake/jump/spin）/ 粒子类（ping/spray/rise）/
反馈类（haptic/shine）」三组分成 3 个子 task。

## Dependencies

`shipswift-foundation` 的 001（AD-4 结论）~ 004。

### 已撤销的三行（#262 第 1 轮 review）

- ~~`Shine { }` ⇒ `.shine(trigger:)`~~ ⇒ **两种形态并存**。
  原理由是「`.mask(content)` 在 `ViewModifier` 里可行 ⇒ 上游"必须 wrapper"的前提不成立」
  ——它回答的是"能不能用 modifier 实现"，而 AC 约束的是"公开 API 长什么样"。
  且 AC 那份清单里 `Shine` 是**唯一大写**的一项，大小写就是形态标记。
  现新增 `public struct Shine<Content: View>: View`（出现时扫一次，无需调用方持有状态），
  内部**直接复用** `.shine(trigger:)`（"这件事刚发生"，可重复触发、可与其余七个叠加），
  没有第二套实现 —— `shineContainerDelegatesToModifier` 钉住这一点，
  因为容器若自建一套，`MicroInteractionReduceMotionGuard` 三条判据仍会全绿。
- ~~`colors:` ⇒ `palette:`~~ ⇒ **改回 `colors:`**。原理由「与 SwiftUI 渐变的 `colors:`
  撞名但语义不同」不足以抵消"与自己的规格不一致"。
- ~~粒子色默认 `[.accent]`~~ ⇒ **改回默认 `[]` ⇒ `.tint`**。
  ⚠️ 原理由「SwiftUI 无公开 API 把 `.tint` 解析成 `Color`，而粒子需要具体色值」
  **前提是错的**：粒子要的是 `ShapeStyle`，`.foregroundStyle(.tint)` 本来就成立，
  根本不需要"解析成具体色值"。原实现导致调用方 `.tint(.pink)` 对默认粒子色**静默失效**
  ——正是 CLAUDE.md FR-12 段警告的那种情况。
  ⚠️ `.tint` 在静息位图上不可观测（粒子静息 `opacity` 为 0），
  故规则抽成 `[Color].particleColor(at:)` 后在函数层断言，而非渲染层。

## ⚠️ 未验证项：**零视觉验证**（第 3 轮终审 I-4，显式登记）

本 task 的产出是 **8 个纯视觉动效 + 一个新的高光色值 token**，而验证清单里全是

## ⚠️ 曾记为「未满足」、经终审证明**记账本身是错的**（现已满足）

初版这里写着两条 AC 不满足，理由是「环境注入 + 渲染断言在 macOS 单测里不可观测」。
**#262 终审 I-4 证伪了这个理由**，两条现均已满足：

- **「叠加互不干扰……有测试」** ✅ ——⚠️ **但上一版记的理由是错的**：当时用的是
  `ImageRenderer` 的**静息尺寸**相等断言，而第 3 轮终审实测证明
  `offset` / `scaleEffect` / `rotationEffect` / `overlay` / `mask` **全都不改变布局尺寸**
  ⇒ 那条断言对这一族 modifier **结构上不可能判红**，是「运行期恒真」。
  现改为**静息位图**逐字节相等 + 一条**不等**断言互锁（本仓
  `SidebarLeadingSlotRenderTests` 的成法）。
  ⚠️⚠️ **改完抓到的不是"已知例外"，是一个真视觉 bug**（第 4 轮终审 C4-1）：
  上一版把 `.shine` 的静息差异归因于「`.mask` 强制离屏合成 ⇒ 抗锯齿」，
  并为它写了一条「已知例外」测试断言 `bare != shined`
  ⇒ **那条测试实际在保护缺陷**（修好 bug 它就会红）。
  三个对照实验证伪了那个成因（高光设 `.clear`、`Color.clear.mask(content)`
  都与裸视图**逐字节相同**；差异像素全在字形内部、全部变亮）。
  真因：`keyframeAnimator` 的 `initialValue: -travel` 在首次求值时
  `proxy.size == .zero` ⇒ 固化成 0 ⇒ **光带永久停在内容上**，
  `PRO` 胶囊左缘有常驻斜切、`star.fill` 整体被洗淡。
  ⇒ 改成无量纲进度（`travel` 在闭包内相乘）后 `.shine` 静息态逐字节相同，
  **已并回八件套**，例外测试删除。另补一条「八个各自单独用」的逐件断言
  ——叠加相等时两个效果的相反偏差可能互相抵消。
- **「Reduce Motion 降级……测试可证」** ✅ ——`MicroInteractionReduceMotionGuard`。
  ⚠️ **上一版的守卫有一个被实测证伪的宣称**：头注释写「若早就存在，第 1 轮的
  Jump / Spray / Shine 三条会被机器当场逮到」，而评审把第 1 轮源码取出复现判据
  ——Jump 的缺陷是「`offset` 门控了、`scaleEffect` 没门控」，文件里两个关键字都在
  ⇒ **上一版守卫全绿放行**。逮到的只有完全没降级的那三条。
  ⇒ 本版补第三条判据直取该盲区：**不走早退的文件，每一处运动变换的实参里都必须
  自带门控**（配对括号提取，不看行也不看窗口——逐行会误判跨行调用、窗口会被
  紧邻的另一个已门控调用骗过，两种都实测过）。
  **变异实证**：把 Jump 的 `scaleEffect` 去门控（保留 `offset` 的）→ 红。
  形态 2 的豁免也从**文件内自证注释**改成**集中名单 + 双向差集**
  ——自证标记任何人加一行注释即可放行，且长在被审对象自己文件里，评审看不见。

⚠️ **代价如实记录**：这条守卫（**本版**）若早就存在，第 1 轮的 Jump / Spray / Shine
与第 2 轮的 Ping 都会被机器逮到。上一版只逮得到其中三条——差别就在「部分门控」
这一条判据上，而那恰是本 issue 已经真实发生过一次、也最可能再犯的形态。

⚠️ **真正不可观测的只是动画的中间帧**（`ImageRenderer` 拍静态帧，本仓
`ToastPresentationRenderTests` 已写死这条限度）——记账应当写「动画中间帧不可观测」。
⚠️ 初版把这两项「移交 `CoreDesignShaders` 的 `RenderProofTests`」，而那个名字当时
在整个仓库**只出现在那一行**⇒ 移交对象不存在、移交不可执行（终审 I-5）。
