# Task: 转场簇（16 种）

## Description

按 CoreDesign 公约重新实现 ShipSwift `SWTransition.swift` 的 **16 种**转场，
落 `CoreDesignEffects`。CoreDesign 目前**没有任何 `Transition` 实现**，
调用方只能用 SwiftUI 内建的 `.slide` / `.opacity`。

## Acceptance Criteria

- [ ] 16 种转场可用：blur / flip / rotate3D / swoosh / boing / skid / move / iris /
      wipe / blinds / clock / flicker / filmExposure / snapshot / glare / dissolve
- [ ] 以 `Transition` 协议实现 + `extension Transition where Self == …` 的静态成员暴露，
      支持 `.transition(.iris)` 点语法
- [ ] 含参重载（如 `.wipe(angle:)` / `.move(angle:distance:)` / `.dissolve(cellSize:)`）
      **算同一种**——计数单位是"一种 transition"不是"一个静态成员"
- [ ] **Reduce Motion 降级**：位移/旋转类降级为淡入淡出，测试可证
- [ ] 各有 `#Preview` + `docs/components/*.md`
- [ ] `EffectsColorLiteralGuard` 零违规

## Technical Details

⚠️ **`Transition` 静态成员不是 `View` / `ViewModifier`**，`ComponentRegistryGuard` 的
`PublicTypeCollector` **结构上扫不到它们** ⇒ 它们不进登记表，也不在 AD-4 差集守卫的射程内，
按 AD-4 的裁决**手工维护并在盲区台账留痕**。

mask reveal 类（iris / wipe / blinds / clock / dissolve）的 `Shape` 数学是上游最有价值的
部分，可直接借鉴。

⚠️ **decompose 必须再拆**：16 种按「滤镜类（blur/filmExposure/snapshot/flicker）/
3D 与弹性（flip/rotate3D/swoosh/boing/skid/move）/ mask reveal（iris/wipe/blinds/clock/
glare/dissolve）」三组，每组一个子 task。
