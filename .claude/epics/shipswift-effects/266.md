# Task: 转场簇 A：滤镜类（4 种）

拆自 #251（16 种转场，XL）的三组之一 —— **滤镜类 4 种**。

## 本子 task 的 4 种

`blur` / `filmExposure` / `snapshot` / `flicker`

这组的共同点是**不改变几何、只改变成像**，因此 Reduce Motion 的降级形态与位移类不同：它们本就没有位移，需要逐个判断「闪烁 / 曝光跳变」是否构成前庭不适风险（`flicker` 尤其——闪烁是 WCAG 明确点名的诱因），不能一律套「降级为淡入淡出」。**请在实现里逐个写明该转场的 Reduce Motion 判据与理由。**

## 公共约束（三个子 task 相同）

- **形态**：`Transition` 协议实现 + `extension Transition where Self == …` 的静态成员暴露，支持 `.transition(.iris)` 点语法。
- **含参重载算同一种**：计数单位是「一种 transition」不是「一个静态成员」；扫描器按 `Host.member` 去重，与此同一口径。
- **登记**：每个转场必须登记进 `docs/component-registry.json` 的 `entryPoints` 数组（`target` / `host` / `member` / `notes` 四字段），由 `ExtensionEntryPointGuard` 做双向差集——漏登记与幽灵条目**两个方向都判红**。⚠️ `notes` 有 schema 校验：≥10 字符、不得含空话占位词（`历史遗留` / `TODO` / `TBD` / `待定` / `占位符` / `见上` / `同上` 等），写各自的承重契约。
- **Reduce Motion 降级**：位移 / 旋转类降级为淡入淡出，**测试可证**。
- **`EffectsColorLiteralGuard` 零违规**；文案若有则受 `ChromeTextLiteralGuard` 约束（A 类）。
- 各有 `#Preview` + `docs/components/*.md`。

## ⚠️ 并行冲突面（三个子 task 之间）
