# Task: 转场簇 C：mask reveal（6 种）

拆自 #251（16 种转场，XL）的三组之一 —— **mask reveal 6 种**。

## 本子 task 的 6 种

`iris` / `wipe` / `blinds` / `clock` / `glare` / `dissolve`

⚠️ **#251 内部有一处出入**：其 Technical Details 写「mask reveal 类（iris / wipe / blinds / clock / dissolve）」是 **5 个**，而 decompose 分组把 `glare` 也划进本组是 **6 个**。本子 task 按 **decompose 分组**走（6 个），因为只有这样三组才凑满 16 种且无重叠。若实现中发现 `glare` 的数学更接近滤镜类，可以调整归属，但**必须同步改 #251 的分组说明**，不要让两处继续打架。

#251 明确指出「mask reveal 类的 `Shape` 数学是上游最有价值的部分，可直接借鉴」—— 这组的核心工作量在 `Shape` / mask 几何，不在动画曲线。

⚠️ 含参重载：`.wipe(angle:)` / `.dissolve(cellSize:)` 等**算同一种**，登记表里各占一条。

## 公共约束（三个子 task 相同）

- **形态**：`Transition` 协议实现 + `extension Transition where Self == …` 的静态成员暴露，支持 `.transition(.iris)` 点语法。
- **含参重载算同一种**：计数单位是「一种 transition」不是「一个静态成员」；扫描器按 `Host.member` 去重，与此同一口径。
- **登记**：每个转场必须登记进 `docs/component-registry.json` 的 `entryPoints` 数组（`target` / `host` / `member` / `notes` 四字段），由 `ExtensionEntryPointGuard` 做双向差集——漏登记与幽灵条目**两个方向都判红**。⚠️ `notes` 有 schema 校验：≥10 字符、不得含空话占位词（`历史遗留` / `TODO` / `TBD` / `待定` / `占位符` / `见上` / `同上` 等），写各自的承重契约。
- **Reduce Motion 降级**：位移 / 旋转类降级为淡入淡出，**测试可证**。
- **`EffectsColorLiteralGuard` 零违规**；文案若有则受 `ChromeTextLiteralGuard` 约束（A 类）。
- 各有 `#Preview` + `docs/components/*.md`。
